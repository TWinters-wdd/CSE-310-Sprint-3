# Goal Program

This program is a terminal-based program where the user can create a One Time goal, a Forever Goal, and a Multi Time Goal. This program allows for users to create the goals, and they can save the goals to a file or load them from a file. In the future, the program will be built in a GUI.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Go to jdk.java.net and click on OpenJDK 27
2. Download the build for your system
3. Follow the steps in the following link [Microsoft Java Installation](https://code.visualstudio.com/docs/languages/java)

Instructions for using the software:

1. Download the Repository
2. Open in VSCode
3. Go to Program.java and run it from there

## Development Environment
